# Révolution — 1789–1799

A bilingual English/French introduction to the French Revolution for secondary-school students. Ten freely explorable moments, interactive explanatory diagrams, historical source links and reduced-motion support. Static HTML, CSS and JavaScript; no installation or build required.

Serve `dist` with any static HTTP server. For example: `python -m http.server 4173 --directory dist`.

Historical artwork: Jean-Pierre Houël, *La Prise de la Bastille* (1789), Bibliothèque nationale de France, via Wikimedia Commons. Public domain. Full historical references and interpretation notes are available in the website’s Sources dialog.
